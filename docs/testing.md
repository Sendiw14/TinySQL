# Testing and evidence commands

Run from the repository root. CI runs the same commands (`.github/workflows/ci.yml`).

| Check | Command | What it proves |
|---|---|---|
| Rust format | `cargo fmt --all -- --check` | formatting only |
| Rust lint | `cargo clippy --workspace --all-targets -- -D warnings` | no lint warnings |
| Rust tests | `cargo test --workspace --all-targets` | currently one skeleton test; no engine behavior |
| Rust release build | `cargo build --workspace --release` | it compiles |
| Advisories and licenses | `cargo deny check` | dependency policy (`deny.toml`) |
| Golden fixtures up to date | `python3 scripts/fixtures/run.py check` | committed fixtures equal the generators; every error code is registered |
| API fixtures match schema | `python3 scripts/check-api-fixtures.py` | each fixture body validates against `docs/api/openapi.yaml` (needs PyYAML, jsonschema) |
| Route matrix | `scripts/gen-route-matrix.sh --check` | 11 public + 7 Studio routes, CSV current |
| Token contrast | `node scripts/contrast.mjs` | token pairs meet WCAG ratios (math only, not rendered UI) |
| Requirements | `python3 scripts/release-gate.py --report` | matrix is well-formed; counts by status |
| Release gate (M8) | `python3 scripts/release-gate.py` | exits 1 until every MUST is PASS |

Fixture rules (ADR-12): fixtures are generated by independent Python reference code in `scripts/fixtures/`. Never edit a fixture to make a failing implementation pass; change the ADR first.
